# Japanese Whisky IG Media Auto-Poster

Instagram自動投稿用の動画・キャプション公開・在庫リポジトリ（@japanesewhisky.lab用）。**ストーリーズ＋リールに同じ動画**を投稿する（フィード投稿は行わない）。

`morimotogrowship-alt/tmp`（美容カテゴリ用）と同じ仕組みだが、ストーリーズ用の静止画は使わず、**ストーリーズ・リールとも同一の動画ファイル**を使う点が異なる（銘柄ごとにhero/guideの2枚の静止画があり、リール動画は既にその2枚をクロスフェードした構成のため）。

## 仕組み（スケジュール投稿）

1. `videos/`（縦型mp4、リール用に生成済みの動画をそのまま使用）に動画、同名の `.txt` キャプションを `captions/` に置いてpushしておく（＝「投稿案の在庫」を積んでおくだけで、この時点では投稿されない）
2. 海外（北米＋欧州）向けのため毎日**2回**、UTC 18:13（欧州の現地19-20時台目安）・UTC 23:13（北米東部の現地19時台目安）に GitHub Actions が自動起動（「最適時間」は確定統計ではなく一般的な目安。サマータイム切り替わり時は現地時間が前後1時間ズレる）
3. 在庫の中から**先頭の1件だけ**（ファイル名の先頭数字が小さい順、例: `01_...` → `02_...`）を選んで投稿
   - ストーリーズ：動画を使用（キャプションは付かない仕様）
   - リール：同じ動画を使用（キャプション付き）
4. 投稿が完了した項目は `posted.json` に記録した上で、**`videos/` `captions/` から自動削除**（在庫から除外し、二重投稿を防止）
5. 手動で今すぐ1件投稿したい場合は Actions タブから `workflow_dispatch` で手動実行も可能

## 使い方

このリポジトリを直接操作する場合は：

- `videos/05_銘柄名.mp4` を追加（ストーリーズ・リール共用の縦型動画）
- `captions/05_銘柄名.txt` にキャプション本文を書く（このファイルが無い/空の場合はスキップされ、在庫としてもカウントされない）
- `git add . && git commit -m "add: 05" && git push`
- 次回のスケジュール実行（または手動実行）で、在庫の中の順番が来たら自動投稿される

## 必要なリポジトリ設定

- Settings → Secrets and variables → Actions → New repository secret
  - Name: `IG_ACCESS_TOKEN`
  - Value: `@japanesewhisky.lab` に紐づくテスト済みのInstagramアクセストークン
